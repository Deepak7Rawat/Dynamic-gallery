## ✦ Overview

**Gallery** is a simple, beginner-friendly web page built using **HTML5 and CSS3**.

The project uses **CSS Flexbox** to divide the page into four equal-width columns, with multiple images arranged vertically inside each column.

The layout focuses on learning **Flexbox, image sizing, spacing, and basic page structure**.

## ✦ Design

The project follows a simple visual structure:

**Heading → Four Columns → Multiple Images**

The main gallery container uses:

```css
display: flex;
```

Each `.box` takes **25% width**, creating four equal columns.

Images are given:

```css
wid
```
